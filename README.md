🤖 ML Model Collection

ML Model Collection is a Python-based machine learning repository containing model-development code for three NLP applications: Social Media Platform Detection, Spam Message Detection, and Sarcasm Detection. The project demonstrates how text data can be processed, transformed into machine-readable features, used to train classification models, and evaluated for prediction.

✨ Projects

📱 Social Media Platform Detection

Analyzes text and predicts the social media platform it is most likely associated with, such as Facebook, WhatsApp, Twitter, or Instagram.

📩 Spam Message Detection

Processes message text and classifies it as Spam or Not Spam, demonstrating practical text classification for message filtering.

😏 Sarcasm Detection

Analyzes text and predicts whether the given sentence is Sarcastic or Not Sarcastic, focusing on identifying contextual patterns in language.

📂 Project Structure

The repository contains Python code for developing three different machine learning models focused on text classification and detection.

* Social Media Detector/ – Python files for detecting the social media platform associated with given text.
* Spam Message Detector/ – Python files for detecting whether a message is spam or not.
* Sarcasm Detector/ – Python files for detecting whether given text is sarcastic or not.

🎯 Project Purpose
The purpose of this repository is to maintain the Python source code used to develop multiple text-classification models in one place. It provides a foundation for experimenting with NLP and machine learning while preparing trained models for integration into applications such as Android, web, or other client applications.
